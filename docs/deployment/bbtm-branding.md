# Identité de l’application BBTM

Le nom affiché de l’application est BBTM dans le menu, l’onglet du navigateur,
les écrans de connexion et d’activation, les invitations, les messages et les
modules métier. Le logo BBTM existant est conservé.

Les nouveaux exports PDF et calendriers utilisent BBTM comme marque et comme
créateur. Les propriétés des deux modèles contractuels PDF utilisent également
BBTM ; les pages et le texte contractuel sont conservés.

Les libellés de provenance historiques sont présentés sous BBTM dans le planning
et les bibliothèques QHSE. Les identifiants persistés, UID de calendrier, règles
d’accès, migrations déjà appliquées, noms du dépôt et adresses de déploiement
sont conservés pour maintenir les liens et la compatibilité des données.

Aucune migration de base de données ni nouvelle variable d’environnement n’est
requise. Le déploiement s’effectue par le pipeline Vercel existant.
