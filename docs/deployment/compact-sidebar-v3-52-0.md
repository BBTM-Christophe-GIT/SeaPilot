# Barre latérale compacte — v3.52.0

La proposition 2 retenue utilise un fond bleu nuit continu, des séparateurs fins, des icônes de rubrique colorées et des lignes plus compactes. Toutes les rubriques sont ouvertes à l'arrivée ; leur repli reste indépendant. Planning et Administration gardent leur accès direct. La version et la commande de réduction partagent une ligne en bas du menu.

Les trois accès du registre utilisent des pictogrammes distincts : une manille pour les apparaux, un segment de câble sans boucle pour les remorques maritimes, un crochet pour l'examen à fond de grue. Les PNG transparents sont appliqués en masques pour suivre la couleur du lien.

Les routes, permissions, protections de saisie du levage et notes non lues sont conservées. Le menu mobile garde son volet et les cibles tactiles de 44 px. Aucun changement de base de données, de configuration ou de catalogue des notes de mise à jour.

Validation : tests de navigation (ouverture initiale, repli indépendant, réduction), profils existants, routage et notes de mise à jour ; build de production ; contrôle visuel ordinateur/mobile décrit dans `design-qa.md`.
