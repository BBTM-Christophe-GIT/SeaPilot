# Certificats flotte — hiérarchie des catégories (v3.21.5)

## Arborescence documentaire

- les sous-catégories du catalogue sont maintenant regroupées sous leur catégorie parente ;
- une catégorie parente est affichée même lorsqu'elle ne contient directement aucun document ;
- les sous-catégories et leurs documents bénéficient d'un niveau d'indentation distinct ;
- les compteurs de documents et d'écarts de la catégorie parente incluent ses sous-catégories.
- la sélection d'une catégorie parente applique le périmètre à ses documents directs et à ceux de ses sous-catégories.

Exemple attendu : `07 - LSA` contient `07.1 - Radeaux / HRU`, qui contient ensuite les documents associés.

## Rapport « Certificats Flotte - Plan d'Action »

- les catégories parentes sont présentées avant leurs sous-catégories ;
- les sous-catégories utilisent un rang visuel inférieur dans les rapports avec documents, écarts, ou les deux ;
- les en-têtes de continuation rappellent les deux niveaux de classement ;
- le format compact conserve sur une seule page A4 un rapport d'un navire comprenant 18 documents.

La hiérarchie s'appuie sur le catalogue applicatif existant ; aucune migration de données n'est nécessaire.
