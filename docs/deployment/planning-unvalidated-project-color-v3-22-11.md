# SeaPilot v3.22.11 — projets non validés dans le planning

## Évolution

Dans la frise du module Planning, les projets dont le statut normalisé est `Non validé` utilisent désormais un fond jaune/orangé avec un texte brun foncé.

La géométrie de la barre, ses interactions, son libellé et les couleurs des autres statuts restent inchangés. Les états de survol, de sélection et de focus conservent le même code couleur avec un contraste adapté.

## Recette

1. Ouvrir le module Planning en vue flotte.
2. Repérer un projet au statut `Non validé` et vérifier son fond jaune/orangé.
3. Vérifier qu'un projet `Validé`, `Stand-by météo` ou `Facturé` conserve sa couleur habituelle.
4. Contrôler le survol, la sélection et l'ouverture de la fiche du projet.
