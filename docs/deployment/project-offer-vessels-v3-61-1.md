# Offre commerciale — navires, v3.61.1

Dans l’assistant projet, les champs **Navire principal** et **Navire secondaire** se trouvent dans **Offre Commerciale**, immédiatement avant le loyer d’affrètement. Ils restent accessibles en mode « Description libre et annexes ».

L’étape **Facturation**, la zone d’opération et les options ROV/plongée sont masquées pour ce type de contrat. Les documents deviennent la quatrième étape du parcours. Un changement de type depuis Facturation vers Offre Commerciale ouvre automatiquement l’offre.

Les sélections, le classement des navires et leur enregistrement restent identiques. Les autres types de contrat conservent leur parcours à cinq étapes. Aucune migration ni variable de configuration n’est nécessaire.

Validation : tests existants de l’éditeur, contrôle visuel du formulaire et des changements de type, compilation de production avec pnpm 10.34.5.
