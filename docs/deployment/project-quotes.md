# Devis et offres commerciales

Dans **Opérations → Devis**, les profils Administration et Direction disposant
de l’accès à Projets peuvent créer une offre. Le devis rejoint le portefeuille
Projets au statut **Non validé**. Le code est attribué à l’enregistrement.
L’identité de l’armateur reprend la valeur par défaut de Nouveau projet.

1. Renseigner le nom du projet, le client et la description.
2. Préparer la localisation avec les outils cartographiques de Projets.
3. Choisir le navire principal, la présentation des conditions et le traitement
   du fuel. Les ports et la date de début d’affrètement se saisissent dans
   **Offre commerciale**.
4. Dans **Émission du document**, sélectionner la carte et les brochures à
   joindre, puis cliquer sur **Exporter l’offre commerciale**. L’export
   enregistre le devis et verse l’offre PDF dans le dossier Projet. Les
   brochures choisies sont intégrées en pièces jointes à l’offre et proposées
   chacune en PDF à télécharger.

Le parcours utilise les droits d’accès, l’enregistrement et le stockage des
documents de Projets. Aucune migration de base de données n’est nécessaire.
