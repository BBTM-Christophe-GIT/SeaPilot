# Projets — coûts facultatifs du remorquage (v3.24.2)

## Changement

- La valeur par défaut du champ `13. Coûts additionnels facultatifs` est désormais une phrase continue, sans saut de ligne entre le tarif portuaire et le tarif en mer.
- Les contrats qui contiennent encore exactement l’ancienne valeur par défaut avec une ligne vide sont affichés avec la nouvelle présentation.
- Les textes personnalisés saisis par les utilisateurs restent inchangés.

## Valeur par défaut

`Remorqueur au port : 3400€ HT / 24h. Remorqueur en mer : 4900€ HT / 24h (fuel inclus)`
