# Projets — présentation des coûts facultatifs du remorquage (v3.24.3)

## Changement

- La valeur par défaut du champ `13. Coûts additionnels facultatifs` est présentée sur deux lignes consécutives, sans ligne vide.
- Chaque tarif se termine par un point.
- Les anciennes valeurs par défaut, avec une ligne vide ou sur une seule ligne, sont automatiquement affichées avec la nouvelle présentation.
- Les textes personnalisés saisis par les utilisateurs restent inchangés.

## Valeur par défaut

```text
Remorqueur au port : 3400€ HT / 24h.
Remorqueur en mer : 4900€ HT / 24h (fuel inclus).
```
