# Logo SeaPilot orange

Le logo partagé `public/seapilot-logo.png` utilise désormais l’orange pour le
point du « i » et la signature « by BBTM », à la place du bleu. Le symbole,
le nom blanc, le fond noir et les dimensions de l’image sont conservés.

Le composant `SeaPilotLogo` diffuse ce visuel dans la navigation, les écrans
de connexion et de définition du mot de passe, ainsi que l’écran de
configuration. Aucune migration, dépendance ou variable d’environnement
supplémentaire n’est nécessaire. Le pipeline Vercel existant publie l’image.
