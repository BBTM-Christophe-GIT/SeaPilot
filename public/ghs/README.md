# Pictogrammes SGH

Illustrations officielles OSHA téléchargées le 22 septembre 2026 depuis
https://www.osha.gov/hazcom/pictograms (PNG : exploding-bomb, flame, flame-over-circle,
gas-cylinder, corrosion, skull-and-crossbones, exclamation-mark, health-hazard, environment).
Codes du système général harmonisé GHS01–GHS09, libellés français dans chemicalModel.ts.
Les pictogrammes ne sont pas attribués automatiquement : la sélection est reprise du
document fourni ou renseignée par l'utilisateur d'après la FDS.
