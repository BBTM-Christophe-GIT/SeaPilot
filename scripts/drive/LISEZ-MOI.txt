SEAPILOT - LANCEUR WINDOWS COMMUN 2.3.0
PROCEDURES, PDF ET DOSSIERS AUTOMATIQUES - 25/09/2026

Une installation pour Procedures, Procedures PDF, Sanctions Disciplinaires, Produits Chimiques et les futurs modules.

1. Installez Google Drive pour ordinateur et connectez votre compte autorise.
2. Verifiez que SeaPilot est visible dans l'Explorateur. Les sous-dossiers des modules sont crees automatiquement. Procedures et Sanctions Disciplinaires doivent etre reserves a Administration et Direction dans les partages Google Drive.
3. Extrayez entierement cette archive puis executez Installer.cmd une fois. Word et Excel doivent etre installes pour modifier leurs documents.
4. Ouvrez Administration > Documents et Google Drive dans SeaPilot. Renseignez la racine (exemple G:\Mon Drive\SeaPilot) et enregistrez-la : les dossiers des collaborateurs en poste sont prepares.
5. Autorisez l'ouverture du lanceur et la connexion locale si le navigateur le demande.

Le chemin est memorise par utilisateur Windows sur ce PC. Aucun chemin par module n'est a configurer. Une nouvelle installation est inutile pour ajouter un sous-dossier de module.
Les anciens reglages de modules sont conserves pendant la mise a jour. Le reglage commun SeaPilotRoot devient prioritaire.
En cas d'erreur CS0016 avec une ancienne archive, telechargez la nouvelle archive et relancez Installer.cmd. L'installation compile maintenant un fichier distinct puis met a jour le raccourci commun : aucun fichier utilise n'est ecrase et les transferts en cours peuvent se terminer. Les anciens executables restent dans le dossier d'installation.
La version 2.1 contourne automatiquement les ports Windows reserves ou occupes (erreur de socket 10013/10048). Si le lanceur est deja installe, relancez Installer.cmd depuis cette nouvelle archive : la racine Drive est conservee, sans refaire sa configuration.
Apres installation, rechargez la page SeaPilot, puis cliquez sur Verifier ce PC dans Administration > Documents et Google Drive. Si la connexion reste impossible, autorisez l'ouverture du lanceur et la connexion locale pour SeaPilot dans votre navigateur. Le chemin deja enregistre est conserve.

Classement : SeaPilot / Sanctions Disciplinaires / Prenom NOM - c<entreprise>-p<collaborateur> / AAAA-MM-JJ / fichier.
Le dossier est retrouve par son identifiant stable si le nom RH change. Aucun fichier existant n'est ecrase. Taille maximale : 25 Mo. Executables, documents a macros, traversees de chemins et jonctions sortantes refuses.

Le lanceur ouvre les documents autorises dans leur application Windows et peut enregistrer les documents des modules autorises par SeaPilot. La connexion locale est temporaire (3 minutes), limitee a ce PC et aux origines SeaPilot prevues. Chaque ecriture verifie le compte SeaPilot et ses droits aupres du serveur. Aucun mot de passe ni jeton de connexion n'est memorise dans le lanceur. Aucun service ni demarrage automatique n'est installe.

Google Drive assure la synchronisation apres ecriture ou sauvegarde dans Office. Attendez qu'elle soit terminee avant d'utiliser les fichiers sur un autre PC.
Les droits SeaPilot et les partages Google Drive sont independants. Retirez les partages Drive devenus injustifies et gerez les copies locales lors d'un changement d'habilitation. Le lanceur ne change pas les permissions Drive.
Un fichier deplace ou renomme necessite de mettre a jour sa reference dans SeaPilot. Les PDF publies restent des versions distinctes des fichiers de travail.

Desinstallation : supprimer HKCU\Software\Classes\seapilot-drive et le dossier %LOCALAPPDATA%\SeaPilotDrive. Le reglage est dans HKCU\Software\SeaPilot\Drive (SeaPilotRoot). Les documents Drive ne sont pas supprimes.

Produits Chimiques (2.2) : SeaPilot / Produits Chimiques / NAVIRE - c<entreprise>-v<navire> / <produit> / <piece>-fichier. Fichiers PDF, PNG, JPEG, DOCX, XLSX et TXT, 20 Mo maximum. Les dossiers sont prepares au premier ajout.
Les fichiers sont stockes exclusivement dans ce dossier Google Drive. SeaPilot conserve leur reference, taille et empreinte SHA-256. Le retrait dans SeaPilot preserve le fichier original.
Le telechargement et les annexes PDF lisent uniquement une piece enregistree et autorisee par le serveur. Chaque lecture controle le compte, le produit, la piece, le chemin exact, la taille et son empreinte. Aucun acces de lecture generique aux autres dossiers. Si un fichier change ou est deplace sur Drive, ajoutez sa nouvelle version dans SeaPilot.
Partagez Produits Chimiques avec les profils concernes dans Google Drive. Attendez la synchronisation avant de changer de PC.

Procedures (2.3) : Nouveau document cree une copie Word ou importe un fichier dans SeaPilot/Procedures. Le nom est Theme Numero Version - Titre. Ouvrir cree la fiche, ferme la fenetre puis lance le document. Publier convertit la version enregistree dans Office en PDF dans SeaPilot/Procedures PDF. Word, Excel ou PowerPoint doit etre installe pour les formats correspondants. 25 Mo maximum. Un nom deja utilise par un contenu different est refuse : incrementez la version. Les PDFs sont verifies par empreinte avant lecture et restent accessibles uniquement aux profils autorises. Le lanceur ne modifie jamais les permissions Google Drive.
